XER HOLDPOINT

XER Holdpoint collects no data of any kind.

There is no server. The application has no back end, no account system, no analytics and no telemetry. It contains no networking code whatsoever — no fetch, no XMLHttpRequest, no beacon, and no external font, script or stylesheet.

What happens to your files

  • Files you open are read into your device's memory and processed there.
  • Your original file is only ever read. It is never modified and never written to.
  • Output files are created on your device and saved by you, to wherever you choose.
  • No file, and no information about any file, is transmitted anywhere.

What is stored on your device

  • A single flag recording that you have read the terms shown on first run. It is held in your browser's session storage and is cleared when you close the application.
  • The offline application shell, so it runs without a connection.

Nothing else is stored. No schedule data, no file names, no mapping key and no settings persist after you close the application.

Verifying this yourself

You do not have to take it on trust. Open your browser's developer tools, switch to the Network tab, and run a file through. You will see no requests at all. The source is readable and unobfuscated, deliberately.
