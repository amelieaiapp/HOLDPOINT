Before you use this tool

Please read these five points. They are short because they matter.

  1. This tool removes what is on its list. It keeps only the fields it recognises as schedule structure and removes or empties everything else, including fields it has never seen. That is a strong design, but it is not a guarantee about your particular file.
  2. You must check the output yourself before you send it. The tool will not release a download until you have opened the review panel. This step is not a formality.
  3. Removing names is not the same as making a file untraceable. Real dates, durations, working calendars and the shape of the network remain, because the schedule would be useless without them. A distinctive project can sometimes be recognised from those alone.
  4. Your original file is never modified. It is read into memory and left alone. Work on a copy anyway.
  5. No warranty. This software is provided as is, without warranty of any kind as to completeness or fitness for purpose. You are responsible for verifying the output before disclosure. Liability is limited to the amount you paid for the licence.
